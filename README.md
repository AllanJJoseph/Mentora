# 🚀 Mentora

> Your AI-Powered Career & Learning Companion

Mentora is an intelligent mentorship platform designed to help students and aspiring professionals receive personalized career guidance, skill recommendations, learning roadmaps, and mentorship support. The platform leverages AI to provide tailored insights, track progress, and assist users in achieving their academic and professional goals.

## ⚙️ Installation

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/AllanJJoseph/Mentora.git
cd Mentora
```

### 2️⃣ Install Dependencies

```bash
npm install
```

### 3️⃣ Configure Environment Variables

Create a `.env` file in the root directory:

```env
VITE_FIREBASE_API_KEY=your_api_key
VITE_FIREBASE_AUTH_DOMAIN=your_auth_domain
VITE_FIREBASE_PROJECT_ID=your_project_id
VITE_FIREBASE_STORAGE_BUCKET=your_storage_bucket
VITE_FIREBASE_MESSAGING_SENDER_ID=your_sender_id
VITE_FIREBASE_APP_ID=your_app_id

VITE_GEMINI_API_KEY=your_api_key
```

### 4️⃣ Start Development Server

```bash
npm run dev
```

Application will run on:

```bash
http://localhost:5173
```
